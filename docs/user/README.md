# User documentation

For everyone who uses chat.gsi.de, from asking a first question to administering
the corpus.

## Read in order

1. **[Getting started](getting-started.md)** — logging in, the interface, your
   first question. Ten minutes.
2. **[Asking questions](chatting.md)** — Fast vs. Deep, citations, editing a
   question, attaching images.
3. **[Files and storage](files-and-storage.md)** — uploads, generated files, your
   quota.
4. **[What you can search](access-and-knowledge-bases.md)** — why the assistant
   knows about some things and not others.

- **Administrator** (`llmbot-admin`) → [Administration](administration.md) and

## When something is wrong

[Troubleshooting](troubleshooting.md) covers the problems a user can actually fix.
Anything else starts at `http://status.lab`, which tells you whether the system
knows it is broken.

## A note on language

The interface is German (`Einstellungen`, `Verwaltung`, `Administration`,
`Quellen`). Answers follow the language of your question — ask in English, get
English. These docs use the German labels where they appear on screen, so you can
find them.
